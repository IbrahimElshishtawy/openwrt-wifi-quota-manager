# System Services Layer (`openwrt/services/`)

This directory contains service scripts for integrating the Quota Manager into OpenWrt's native **`procd`** process supervision system.

---

## ⚙ Why `procd`?

Instead of invoking Python manually from an interactive terminal, OpenWrt uses `procd` (Process Daemon) to:
1. **Boot Automation**: Start services automatically upon router boot (via `/etc/rc.d/` symlinks generated by `START=95`).
2. **Crash Supervision**: Automatically respawn crashed processes.
3. **Log Aggregation**: Redirect stdout and stderr directly to OpenWrt's system log (`logread`).
4. **Clean Shutdown**: Gracefully terminate and clean up state when the router reboots.

---

## 📥 Installing the Service on OpenWrt

To register `quota-manager` as an OpenWrt system service:

```bash
# 1. Copy the init script to /etc/init.d/
cp /root/openwrt-wifi-quota-manager/openwrt/services/quota-manager.init /etc/init.d/quota-manager

# 2. Grant executable permissions
chmod +x /etc/init.d/quota-manager

# 3. Enable the service to run at boot
/etc/init.d/quota-manager enable

# 4. Start the service immediately
/etc/init.d/quota-manager start
```

---

## 🕹 Service Management Commands

| Action | Command |
| :--- | :--- |
| **Start Service** | `/etc/init.d/quota-manager start` |
| **Stop Service** | `/etc/init.d/quota-manager stop` |
| **Restart Service** | `/etc/init.d/quota-manager restart` |
| **Reload Config** | `/etc/init.d/quota-manager reload` |
| **Check Status** | `/etc/init.d/quota-manager status` |
| **Inspect Logs** | `logread -e quota_manager` |

## 🔮 Future Services (`quota-api`)

When the local REST API is introduced, a complementary service script (`/etc/init.d/quota-api`) will be deployed to keep the lightweight API daemon running continuously on a designated local port (e.g., `8080` or `8443`).
